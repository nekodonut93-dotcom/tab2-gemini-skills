# Seedance portable examples

All examples are synthetic and illustrate the portable contract; they are
not production prompt-template evidence or Gemini benchmark results.

- `good/` includes dialogue, hospital, sourced sword action, vehicle arrival,
  comedy reaction, Chinese 3D/chibi, realistic, wuxia, and confirmed
  multi-reference examples.
- `bad/` contains invalid additions such as unsupported VFX and invented
  platform syntax.
- `blocked/` contains unresolved action and style/reference cases.

Examples deliberately separate source semantics, visual profile, Director
HOW, and Dola UI syntax.
