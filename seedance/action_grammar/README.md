# Action grammar

Use the source action interpreter and choreography add-ons before describing
physical action. Every motion remains subordinate to the Writer's sourced
action. The semantic action class, actor, target, direction, contact, and
outcome must not become more specific than source/context evidence.

Choreography phases are optional: pre-action, anticipation, primary action,
follow-through, reaction, settle. Prompt prose should use only phases needed
to communicate the action, and should omit ungrounded contact/result.

No phrase here authorizes an invented jump, spin, impact, injury, magic, or
story event.
