# Model-neutral rules

These semantic rules apply equally to Gemini Web, ChatGPT Web, and future
API-facing wrappers. Packaging, UI formatting, and provider syntax may differ;
authority, evidence, visibility, failure, Writer WHAT, Director HOW, and
PromptEngine boundaries may not.

Never put provider credentials in portable state or manifests. Model adapter
records describe evidence status, not a provider API guarantee. Do not infer
capability from a model's name or from an unrelated skill compatibility list.
Visual style is an explicit project preference, not something inferred from
the source novel or selected Gemini model.
