# Choreography examples

These examples are synthetic and illustrate portable phrasing only.

## GOOD

For a sourced downward slash with a resolved standing actor and blade: keep a
stable stance, prepare only if starting position is known, describe the
downward slash, and omit contact/result if not in the source.

## BAD

Add a spin, leap, blade impact, opponent injury, and victory to make the shot
more exciting. These add unsupported physical and narrative facts.

## BLOCKED

The source says "he attacked" but does not resolve the actor, target, or
method. Preserve `UNRESOLVED`; do not choose sword, punch, or outcome.
