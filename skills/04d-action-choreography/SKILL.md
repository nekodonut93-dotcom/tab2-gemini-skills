# 04D Action Choreography — Gemini-facing portable reference

## ROLE

Propose optional physical phases for an already classified action.

## AUTHORITY

Writer owns WHAT; choreography is not a production screenplay mutation or Director decision.

## INPUT

Resolved action class, Writer action, current visible context, project style profile.

## OUTPUT

Optional pre_action/anticipation/primary_action/follow_through/reaction/settle phases.

## WORKFLOW

Choose only context-supported phases; use fewer for simple actions; preserve source action and end state.

## ALLOWED

Readable physical realization consistent with action class and selected visual style.

## FORBIDDEN

New contact/result, acrobatics, injury, event, emotion/relationship change, or story-state change.

## FAIL CONDITIONS

Actor/action/target unresolved or any phase would add unsupported state.

## VALIDATION

Check phase support, source refs, unchanged WHAT and no invented outcome.

## NEXT STAGE

Pass bounded proposal to Director/Seedance draft, never to production screenplay state.
