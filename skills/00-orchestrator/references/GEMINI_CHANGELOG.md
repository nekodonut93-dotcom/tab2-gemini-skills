# Gemini distribution changelog

Release metadata is copied from the checked-in Gemini distribution manifests.
This file distinguishes the previous distribution snapshot from the current
additive reference-package release; it does not assert older release history
or production behavior.

## 1.1.0 — 2026-10-07

- Distribution manifest reports `distribution_version: 1.1.0`,
  `generated_from_inventory_version: 2`, and `compatible_architecture_version:
  TAB2-REFERENCE-1`.
- Added five portable add-on skills: visual completion, action interpreter,
  action choreography, Seedance prompt drafting, and style resolution.
- Added a portable `PROJECT_VISUAL_PROFILE.json` template, Seedance scene and
  export schemas, offline contract tests, and deterministic ZIP builds for 13
  per-skill packages.
- Added the Gemini readiness audit, production regression map, and
  Gemini-Web-specific safe-stop example.
- No production runtime, frozen contract, portable schema, Story Memory
  authority, or PromptEngine authority changed. A new portable schema was
  added; existing schemas and frozen identities remain unchanged.
- Release archives are per-skill ZIP files generated by
  `py -3.13 dist/build_distribution.py`.

## Previous checked-in snapshot — 1.0.0

- The snapshot had eight source packages, inventory version 1, and eight
  release archives.
- This repository snapshot did not include a historical changelog before
  that baseline.

## Versioning note

Core source skills retain their declared versions unless their own reference
semantics changed; the orchestrator and quality-audit reference skills use
1.1.0 for additive guidance. New add-ons start at 1.0.0. Do not bump versions
to imply production behavior. Record future releases with the matching source
inventory, compatibility review, regression evidence, and generated archives.
